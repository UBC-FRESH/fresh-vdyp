# VDYP7 source inventory

Date: 2026-11-09
Status: observed from the local VDYP7 installation
Scope: bundle extraction, console runner, and yield-table planning

## Installation shape

The local VDYP7 bundle contains:

```text
VDYP7Console.exe        console yield-table generator
VDYP7Batch.exe          batch runner
WinVDYP7.exe            interactive Windows UI
VDYP7.EXE               legacy front end
VDYPBACK.EXE            backward projection
VDYP7CORE.dll           core model library
VDYP7Interface.dll      extended interface library
VDYP7IO.dll             I/O library
VDYPSI32.dll            site-index library
VDYP_CFG/               control, coefficient, parameter, and report files
```

The binaries are PE32 32-bit Windows executables.

Use `VDYP_INSTALL`, `VDYP_CFG_DIR`, and `VDYP_CONSOLE` for discovery. Do not
commit the installation.

## Control files

## Yield-table schema

`VDYP_CFG/VDYP.tcl` defines 101 output columns. Major groups:

```text
feature / map / polygon / layer keys
year, age
species codes and percentages
stockability
site index, dominant height, Lorey height
diameter, TPH, basal area
whole-stem, close-utilization, decay, waste, and breakage volumes
MoF biomass
species-specific volumes and biomass
CFS biomass
```

The public Volume 3 console guide documents `csvyieldtable` output and the
`VDYP7Console` command line.

## Tracked inventory

`notes/reference/vdyp-bundle-manifest.json` is generated by
`scripts/inventory_vdyp.py`. The install observed on 2026-11-09 has 211 regular
files and 24,742,956 bytes. Inside `VDYP_CFG/coe` it has 40 `.COE`, 7 `.PRM`,
and 33 `.DAT` files (case-insensitive), matching the planning count.

## Parsed control artifacts

`notes/reference/vdyp-ctr.json` records 57 entries, `vdypback-ctr.json` records
55, and `vdyp-columns.json` records 101 columns. They are generated by
`scripts/vdyp_control.py`. `VDYP.CTR` contains a repeated `025` entry whose
second occurrence nullifies the site-curve assignment; the parser preserves
both in file order. `VDYPBACK.CTR` omits sequences `019` and `123`.

## Control-sequence map

`notes/reference/vdyp-control-map.json` joins the 112 control entries to the
install tree: 89 resolve to bundle files, 8 are runtime input/output names, 6
are external paths, 6 are non-file parameters, and 3 are empty nullifications.
No coefficient target is missing. 33 files under `VDYP_CFG/coe` are not
referenced by either control file and remain candidates for later catalog
investigation.

## Structural configuration parse

`notes/reference/vdyp-config-summary.json` records 45 files: 5 control, 7
parameter, and 33 data files, with 3,313 parsed rows. Of the data files, 2 are
one-token lookups (`BEC0.DAT`, `SP0.DAT`) and 31 are token tables. `SIEQN.PRM`
is comment-only and valid with zero records. The summary records structure, not
equation semantics.

## Normalized catalog

`scripts/normalize.py` writes 38 supported families to `data/normalized/`, which
is ignored by Git: 3,260 rows and 182,544 bytes of CSV. The tracked
`notes/reference/vdyp-normalized-manifest.json` records each family's source
file, source SHA256, normalized SHA256, equation family, control sequence, and
row count. `notes/reference/vdyp-normalized-summary.json` records the counts and
the two unsupported families.

## Runtime check

`python scripts/vdyp_runtime.py --check` reports `mode: wine`, Wine 9.0

`VDYP_CFG` configuration directory. The check returns 0 errors and 0 warnings.

`VDYP_INSTALL`, `VDYP_CFG_DIR`, and `WINE`.
