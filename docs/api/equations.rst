``equations``
=============

Validated VDYP7 equation families. The first family is whole-stem volume from
``VTOTREG4.COE``, ported from the public ``bcgov/nr-vdyp`` source with
attribution. Coefficients come from the bundle, and each result carries an
explicit ``validated``, ``experimental``, or ``not_implemented`` status.
