fresh-vdyp
==========

A public, tested Python package for reading the BC VDYP7 coefficient and control bundle, wrapping the VDYP7Console runner, exposing typed yield curves, and validating incremental Python growth equations against the official console outputs. It is an interoperability and reimplementation layer, not a claim of authorship over BC government models or data.

This site is the RTFM surface for the project. Agents read the relevant page before
they act, and cite it in their reports. Start with the repository's ``AGENTS.md`` and
``ROADMAP.md``, and add guides, reference contracts, and agent protocols here as the
project grows.
